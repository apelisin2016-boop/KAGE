# KAGE — Война пяти деревень

Пошаговая стратегия на гексах: пять деревень, туман войны, бой на карте.

## Запуск

```bash
npm install
npm run dev
```

Откроется локальный сервер. Старт: **Начать войну** или **Тренировочный бой**.

## Управление

- ЛКМ — выбрать отряд / ход / атака
- WASD или стрелки — панорама
- Колёсико, `+` / `−` — масштаб
- `Tab` — следующий отряд
- `C` — столица
- `F` — вся карта
- Пробел — конец хода (в бою — к итогу)

Сохранение в браузере (localStorage).
